Agentic HIL

Your AI agent can develop firmware on its own, because Agentic HIL closes the loop with real hardware. This host serves nothing but the installer, mirrored from the repository.

Linux and macOS

curl -LsSf https://agentic-hil.github.io/i.sh | sh

Windows

powershell -c "irm https://agentic-hil.github.io/i.ps1|iex"

The scripts are also here under their full names, install.sh and install.ps1, and are byte for byte the ones on the repository's default branch. Each release publishes their SHA-256 as assets, so a copy can be checked before it is run: see the README.
